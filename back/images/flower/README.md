# 赏花点图片目录

本目录用于存放赏花点的图片资源。

## 图片命名规范

建议按照以下格式命名图片：
- `zijing1.jpg`, `zijing2.jpg` - 紫荆花
- `sakura1.jpg`, `sakura2.jpg` - 樱花
- `mumian1.jpg`, `mumian2.jpg` - 木棉花
- `taohua1.jpg`, `taohua2.jpg` - 桃花
- `hehua1.jpg`, `hehua2.jpg` - 荷花
- `rose1.jpg`, `rose2.jpg` - 玫瑰

## 图片要求

- 格式：JPG/PNG
- 建议尺寸：800x600 或更高
- 文件大小：建议不超过 2MB

## 使用方法

1. 将图片放入此目录
2. 在管理后台添加/编辑赏花点时，图片 URL 填写：`/images/flower/图片名.jpg`
3. 例如：`/images/flower/zijing1.jpg`

## 当前图片列表

请将实际的赏花点图片放入此目录，替换占位图片。
